# Cambridge award evidence — Xihang Zhou

A static, English-language evidence page for the November 2022 Outstanding Cambridge Learner Award (Top in the World), IGCSE Additional Mathematics (0606).

## Publish with GitHub Pages

1. Create a public repository named `cambridge-award` on GitHub.
2. Upload `index.html`, `award-ceremony.png`, `.nojekyll` and optionally this README to the repository root, then commit.
3. Open Settings → Pages → Build and deployment → Deploy from a branch. Choose `main` and `/ (root)`, then Save.
4. Open the URL GitHub displays, and test it in a private browser window.

No dependencies or build steps are required. The photograph is the original supplied image. This is a personal evidence page, not an official award verification service.
